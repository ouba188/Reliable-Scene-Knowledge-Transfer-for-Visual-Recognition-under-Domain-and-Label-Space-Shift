可以设计成**三个真正相互依赖的创新模块**，但先纠正一个标准：

> **顶刊并不要求“至少三个模块”；硬凑三个模块反而容易被评价为 module stacking。**

例如 AAAI 2025 的 DPA 本身就包含 GDPA、IDSA 和 PCC 三个模块，但其贡献成立的原因是三者共同解决 Universal DAOD 中 shared/private 类对齐问题，而不是因为数量等于三。([AAAI Publications](https://ojs.aaai.org/index.php/AAAI/article/view/33156?utm_source=chatgpt.com "Universal Domain Adaptive Object Detection via Dual Probabilistic Alignment | Proceedings of the AAAI Conference on Artificial Intelligence"))

所以，正确做法不是把“检测器、VLM、扩散模型”分别算成三个创新点，而是让三个模块分别解决三个不可替代的问题，并由同一个数学分解连接：

场景迁移→知识增量→已知／未知闭合\boxed{ \text{场景迁移} \rightarrow \text{知识增量} \rightarrow \text{已知／未知闭合} }

我建议把前面的 KIRC 重构为以下三模块核心算法。暂时工作名可以称为：

Scene–Knowledge Incremental Closure Adaptation\boxed{ \textbf{Scene–Knowledge Incremental Closure Adaptation} }

名称以后再定。

其中：

知识 kik_i 只包含目标端合法可获得的内容，例如：

- 到主航道、入口、锚地和岸线的关系；
    
- 船首方向与航道方向关系；
    
- 局部船群关系；

不包含目标单船 AIS 类型或 MMSI 标签。

对每一个源港口—类别成分：

有如下概率比分解：

三个模块不是并列装饰，而是围绕这个分解运行。

# 二、模块一：跨港口语义场与场景比率模块

## 1. 要解决的问题

同一个原始地理坐标在不同港口没有可比较意义：

(x,y)Hamburg≁(x,y)Singapore.(x,y)_{\mathrm{Hamburg}} \not\sim (x,y)_{\mathrm{Singapore}}.

如果直接对齐经纬度、港口 ID 或整港口 embedding，模型很容易学习港口捷径，而不是迁移结构。

模块一的目标是把每个目标转化到跨港口可比较的语义状态空间。

---

## 2. 跨港口语义状态

定义：

si=Φω(bi, Gp, Mp, Ξp)(2)\boxed{ s_i= \Phi_{\omega} \left( b_i,\, G_p,\, M_p,\, \Xi_p \right) } \tag{2}

其中：

- bib_i：船舶位置和旋转框；
    
- GpG_p：港口图；
    
- MpM_p：成像元数据；
    
- Ξp\Xi_p：整景船舶群体统计。
    

输出可以包括：

ui=[dentrance/Lpdchannel/WpdanchoragedcoastΔθchannelρlocaltraffic-direction state].u_i= \begin{bmatrix} d_{\mathrm{entrance}}/L_p\\ d_{\mathrm{channel}}/W_p\\ d_{\mathrm{anchorage}}\\ d_{\mathrm{coast}}\\ \Delta\theta_{\mathrm{channel}}\\ \rho_{\mathrm{local}}\\ \text{traffic-direction state} \end{bmatrix}.

图结构只是其中一部分。连续距离场、元数据和船群统计不强制图化。多视图知识研究本身已经覆盖结构、语义、表示和模态等不同知识视图，因此“使用多种知识形式”不能单独作为首创主张。([IJCAI](https://www.ijcai.org/proceedings/2025/1197?utm_source=chatgpt.com "A Survey on Multi-View Knowledge Graph: Generation, Fusion, Applications and Future Directions | IJCAI"))

---

## 3. 场景比率

模块一估计源成分 g=(p,c)g=(p,c) 与目标场景状态之间的密度比：

rgS(s)=pg(s)pt(s).(3)\boxed{ r_g^S(s) = \frac{p_g(s)} {p_t(s)}. } \tag{3}

它回答：

> 源港口 pp 中类别 cc 的船舶场景状态，在目标港口是否真实存在？

例如：

- 某个 source class 在目标港口的语义空间几乎没有支持；
    
- 某类船虽然视觉上相似，但在目标大景的尺寸、航向和空间场中不合理；
    
- 某源港口只适合解释目标大景中的部分船群模式。
    

---

## 4. 实现方式

使用一个共享场景编码器与条件比率头：

DθS(s,ep,ec),D_{\theta}^{S}(s,e_p,e_c),

其中 ep,ece_p,e_c 是源港口和类别查询嵌入。

在源港口 meta-target episodes 中训练：

- 正样本：源成分 (p,c)(p,c) 的场景状态；
    
- 负样本：当前无标签伪目标港口的场景状态。
    

平衡采样时：

ℓ^gS(s)=logit⁡DθS(s,ep,ec)\widehat{\ell}_g^S(s) = \operatorname{logit} D_{\theta}^{S}(s,e_p,e_c)

近似：

log⁡rgS(s).\log r_g^S(s).

---

## 5. 模块一的独立创新主张

不能写成“提出一个港口知识编码器”。

更准确的主张是：

> **提出以港口语义关系和整景船舶群体为状态的源港口—类别场景比率，使跨港口迁移首先在可比较的功能状态空间中进行，而非对齐原始坐标或全局域向量。**

# 三、模块二：条件视觉—知识增量比率模块

这是整个方法最重要的模块。

你现有实验中，K 相对 noK 的 BA 增量约为 0.0370.037 个百分点，而 K 与 wrongK 在 21,195 个目标样本中仅改变 3 个最终预测，说明当前模型没有明确分离“视觉已经提供的证据”和“知识真正新增的证据”。

同时，现有主 K 只使用 12 个局部值和 12 个 support 特征，38 个全局设施／OSM 特征没有进入主分支，因此不同知识类型还没有被充分检验。

---

## 1. 条件视觉比率

在给定场景状态 ss 后，估计：

rgV∣S(z∣s)=pg(z∣s)pt(z∣s).(4)\boxed{ r_g^{V\mid S}(z\mid s) = \frac{p_g(z\mid s)} {p_t(z\mid s)}. } \tag{4}

它回答：

> 在相同港口语义状态下，这个 SAR 外观多大程度符合源成分 gg？

---

## 2. 视觉—知识联合比率

估计：

rgVK∣S(z,k∣s)=pg(z,k∣s)pt(z,k∣s).r_g^{VK\mid S}(z,k\mid s) = \frac{p_g(z,k\mid s)} {p_t(z,k\mid s)}.

然后定义核心知识增量算子：

ΔgK(z,k∣s)=log⁡rgVK∣S(z,k∣s)−log⁡rgV∣S(z∣s).(5)\boxed{ \Delta_g^K(z,k\mid s) = \log r_g^{VK\mid S}(z,k\mid s) - \log r_g^{V\mid S}(z\mid s). } \tag{5}

通过概率分解可得：

ΔgK(z,k∣s)=log⁡pg(k∣z,s)pt(k∣z,s).(6)\boxed{ \Delta_g^K(z,k\mid s) = \log \frac{ p_g(k\mid z,s) }{ p_t(k\mid z,s) }. } \tag{6}

---

## 3. 这个算子为什么重要？

### 纯视觉域变化会被消去

即使：

pg(z∣s)≠pt(z∣s),p_g(z\mid s)\neq p_t(z\mid s),

只要：

pg(k∣z,s)=pt(k∣z,s),p_g(k\mid z,s)=p_t(k\mid z,s),

就有：

ΔgK=0.\Delta_g^K=0.

所以普通 SAR 外观漂移不会被错误解释成知识贡献。

### 知识冗余时不应改变预测

若知识完全由视觉和场景状态决定：

K⊥g∣Z,S,K\perp g\mid Z,S,

则知识增量接近零。

### 只有条件关系变化才产生知识证据

例如同样的 SAR 外观和尺度，在某种目标港口空间状态下更符合某一类别关系，则：

ΔgK≠0.\Delta_g^K\neq0.

---

## 4. 三个比率头

为了稳定估计式（1），训练三个共享编码但不同输入的 ratio heads：

DgS(s),D_g^S(s), DgSV(s,z),D_g^{SV}(s,z), DgSVK(s,z,k).D_g^{SVK}(s,z,k).

得到：

ℓgS=log⁡rgS,\ell_g^S=\log r_g^S, ℓgV=log⁡rgSV−log⁡rgS,\ell_g^V = \log r_g^{SV} - \log r_g^S, ℓgK=log⁡rgSVK−log⁡rgSV.(7)\boxed{ \ell_g^K = \log r_g^{SVK} - \log r_g^{SV}. } \tag{7}

完整源成分比率：

Rg(s,z,k)=exp⁡(ℓgS+ℓgV+ℓgK).(8)\boxed{ R_g(s,z,k) = \exp \left( \ell_g^S+ \ell_g^V+ \ell_g^K \right). } \tag{8}

---

## 5. 防止港口捷径

模块二不能只学习：

port ID→class prior.\text{port ID}\rightarrow\text{class prior}.

建议使用三种约束：

### 港口 ID 禁用

不把港口名称、编号直接输入模型。

### 同条件负配对

在同一港口、相近尺寸、相近 SAR 外观和相近元数据下交换知识：

(zi,ki)→(zi,kj−).(z_i,k_i) \rightarrow (z_i,k_j^-).

### 元训练式验证

在源港口伪目标中检查：

ΔgK(zi,ki)>ΔgK(zi,kj−)\Delta_g^K(z_i,k_i) > \Delta_g^K(z_i,k_j^-)

是否能预测真实分类增益。

不要强迫所有 wrongK 都产生大差异。只有真正与图像和场景不相容的知识，才应降低条件证据。

# 四、模块三：通用闭合与未知残差分解模块

## 1. 要解决的问题

目标类别空间可能包含：

- shared 类；
    
- source-private 类；
    
- target-private 类。
    

普通 softmax 会强迫所有目标进入源类别。

Universal DAOD 已经研究 shared/private 类的概率对齐与约束，因此“增加 unknown 类或私有类约束”本身并不新。([AAAI Publications](https://ojs.aaai.org/index.php/AAAI/article/view/33156?utm_source=chatgpt.com "Universal Domain Adaptive Object Detection via Dual Probabilistic Alignment | Proceedings of the AAAI Conference on Artificial Intelligence"))

模块三的区别是：它从源成分相对目标分布的概率比率出发，建立一个目标概率质量闭合方程。

---

## 2. 目标混合假设

设目标联合分布可以写为：

Pt=∑gβgPg+βuPu,P_t = \sum_g \beta_gP_g + \beta_uP_u,

其中：

- g=(p,c)g=(p,c)；
    
- PgP_g：源港口—类别成分；
    
- PuP_u：目标私有类别分布。
    

两边除以 PtP_t：

1=∑gβgRg(s,z,k)+ρu(s,z,k),(9)\boxed{ 1 = \sum_g \beta_gR_g(s,z,k) + \rho_u(s,z,k), } \tag{9}

其中：

ρu=βudPudPt≥0.\rho_u = \beta_u \frac{dP_u}{dP_t} \ge0.

这条闭合式同时表达：

- 哪些源港口—类别能够解释目标；
    
- 哪些源类别在目标中不存在；
    
- 哪些目标样本需要分配给 unknown。
    

---

## 3. 凸闭合求解

对目标大景中的 NtN_t 个候选船舶，计算：

Rig=Rg(si,zi,ki).R_{ig}=R_g(s_i,z_i,k_i).

求：

min⁡β,ρ1Nt∑i[ϕ(∑gβgRig+ρi)+λuρi]+λport∑p,cdport(p,t)βpc+λgroup∑c∥β⋅c∥2+η2∥β∥22s.t.βpc≥0,ρi≥0,∑p,cβpc≤1,(10)\boxed{ \begin{aligned} \min_{\beta,\rho}\quad & \frac1{N_t} \sum_i \left[ \phi \left( \sum_g\beta_gR_{ig}+\rho_i \right) + \lambda_u\rho_i \right]\\ &+ \lambda_{\mathrm{port}} \sum_{p,c} d_{\mathrm{port}}(p,t)\beta_{pc}\\ &+ \lambda_{\mathrm{group}} \sum_c \|\beta_{\cdot c}\|_2 + \frac{\eta}{2}\|\beta\|_2^2\\ \text{s.t.}\quad & \beta_{pc}\ge0,\qquad \rho_i\ge0,\\ & \sum_{p,c}\beta_{pc}\le1, \end{aligned} } \tag{10}

其中：

ϕ(x)=x−log⁡x−1.\phi(x)=x-\log x-1.

它在：

x=1x=1

处最小。

---

## 4. 输出解释

目标类别 cc 的整体质量：

αt,c=∑pβ^pc.(11)\boxed{ \alpha_{t,c} = \sum_p\widehat\beta_{pc}. } \tag{11}

如果：

αt,c≈0,\alpha_{t,c}\approx0,

说明该源类别可能是 source-private。

样本 ii 的类别解释：

qic=∑pβ^pcRi,pc.q_{ic} = \sum_p \widehat\beta_{pc}R_{i,pc}.

unknown 概率：

Pi(unknown)=ρ^iρ^i+∑cqic.(12)\boxed{ P_i(\mathrm{unknown}) = \frac{ \widehat\rho_i }{ \widehat\rho_i+\sum_cq_{ic} }. } \tag{12}

known 类概率：

Pi(c)=qicρ^i+∑c′qic′.P_i(c) = \frac{ q_{ic} }{ \widehat\rho_i+\sum_{c'}q_{ic'} }.

---

## 5. 求解性质

固定三个比率头后，式（10）是凸问题；当：

η>0\eta>0

时，对 β\beta 强凸。

因此可以求得唯一全局最优 β\beta。

固定 β\beta，令：

ei=∑gβgRig,e_i=\sum_g\beta_gR_{ig},

则未知残差具有闭式更新：

ρi∗=[11+λu−ei]+.(13)\boxed{ \rho_i^* = \left[ \frac1{1+\lambda_u} - e_i \right]_+. } \tag{13}

随后可以用 proximal gradient 或 block-coordinate descent 更新 β\beta，并给出目标函数单调下降。

# 九、可以写成论文的三项算法创新

## 创新一

> 提出跨港口语义状态比率模块，将异构港口布局、成像元数据和整景船舶群体映射到可比较的场景状态空间，并估计源港口—类别在目标港口中的场景支持。

## 创新二

> 提出条件视觉—知识增量比率模块，通过联合比率与视觉比率之差，显式分离港口知识相对于 SAR 视觉和场景状态所新增的类别证据，避免将普通视觉域偏移或港口边际先验误认为知识贡献。

## 创新三

> 提出 Universal 概率闭合与未知残差分解模块，在统一凸优化中同时估计源港口—类别成分权重、目标中缺失的源私有类别以及无法由任何源类别解释的目标私有样本。

# 十、最后仍然要提醒

**三模块只是论文结构，不是顶刊保证。**

这三个模块必须满足：

1. 由同一个概率因子分解连接；
    
2. 每个模块有独立失败模式；
    
3. 每个模块可以单独消融；
    
4. 完整方法具有普通 concat、GNN、Universal DAOD 不具备的结果；
    
5. 正确港口知识优于错误／置换知识；
    
6. 在新港口和跨日期采集上成立。
    

如果只是将三个网络分支画成框图，即使名字再新，也不会比一个清楚的单算法更强。

**这一版的优点是：三个模块不是硬凑出来的，而分别对应“目标港口是否支持这个源成分”“知识相对视觉新增了什么”“不能解释的质量是不是未知类别”三个不可互相替代的问题。**
