# E03 配对感知校正：诊断与源折留一评估（结论：不进入下一版）

**问题**：能否只用无标签统计量，逐对判断「该不该做 mean-only 校正」？
**数据**：六折的源端口两两有序配对（A=参考池、B=适配池，均 ≥150 标签、≥2 类）= **52 对**。
**纪律**：统计量只用无标签特征；标签仅用于**事后验证**（计算 delta_acc/delta_ba）。阈值只在**其它折**上选，再用于留出折（leave-one-source-fold-out）。

## 一、诊断：mean-only 在源端口配对上的真实表现

| 指标 | 值 |
|---|---|
| 配对数 | 52 |
| mean-only 为正的配对 | **8 / 52（15%）** |
| delta_acc 均值 | **−0.094** |
| delta_acc 范围 | **−0.621 ~ +0.235** |

⇒ 把适配池的均值平移到参考池坐标，在**大多数配对上是负收益**，最差可达 −62 个点。

## 二、无标签统计量对「正/负」的可分性

| 统计量 | Spearman | AUC | 定向 AUC |
|---|---:|---:|---:|
| delta_entropy（校正前后熵差） | 0.224 | 0.923 | **0.923** |
| conf_after（校正后平均置信度） | −0.179 | 0.080 | 0.920 |
| entropy_after | 0.198 | 0.915 | **0.915** |
| delta_conf | −0.217 | 0.102 | 0.898 |
| conf_before | −0.118 | 0.159 | 0.841 |
| entropy_before | 0.127 | 0.830 | 0.830 |
| energy_dist（能量距离代理） | −0.248 | 0.344 | 0.656 |
| shift_norm（位移范数） | −0.143 | 0.347 | 0.653 |

⇒ 熵/置信度类统计量能较好地区分**正负号**（定向 AUC 0.92）。

## 三、源折留一评估（决定性）

| 统计量（阈值在其它折选） | 规则 Acc | 总是 cross | 总是 mean-only | **配对 oracle** |
|---|---:|---:|---:|---:|
| entropy_before | 0.319 | 0.315 | 0.221 | **0.328** |
| conf_before | 0.319 | 0.315 | 0.221 | 0.328 |
| delta_conf | 0.317 | 0.315 | 0.221 | 0.328 |
| 其余 5 个统计量 | 0.301–0.317 | 0.315 | 0.221 | 0.328 |

**结论**：
1. 最好的规则只比「总是 cross」高 **+0.004**（噪声级）。
2. **配对 oracle 本身也只有 .328 vs .315（+0.013）**——即使逐对知道真值，收益也只有 1.3 个点。
   → **符号可预测，但幅度在这些配对上可忽略**，预测符号并不能换来准确率。
3. 在 5 个可判定伪目标上按同样口径算配对 oracle：Rotterdam→Qingdao +7.5、Port Said→Shanghai +2.0、
   Shanghai→Qingdao +1.6、Fujairah→Shanghai 0、Jebel Ali→Shanghai 0 ⇒ 平均 **+2.2 点**。

## 四、裁定与下一步

- **不把「配对感知的观测条件校正」开发成模块**（配对级可争取的空间约 1–3 个点，且规则在留出折上不可分辨）。
- 三条简单基线（Cross / Mean-only / CORAL-T2S）**保留为参照**：任何后续适配模块必须在这 5 个伪目标上
  超过它们各自的较好者，且要超过**配对 oracle 的 +2.2 点**才有意义。
- 依原裁定表的剩余分支（「两者均未改善，但干净的跨港差距仍明显」）：下一版应做**受源监督约束的小型表示适配模块**，
  在同一 5 个伪目标 + 源港留一上评估。**不**同时改知识/路由/词表。
