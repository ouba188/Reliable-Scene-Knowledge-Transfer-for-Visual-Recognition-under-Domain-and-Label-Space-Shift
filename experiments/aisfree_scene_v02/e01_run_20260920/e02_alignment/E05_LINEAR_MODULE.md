# E05 源监督线性表示适配模块（结论：未达标，不进入下一版）

**允许输入**：D_fit 的 z 与标签、U_q 的无标签 z、E_q 的特征（标签只在评价器）。**未使用**目标真值、未用 U_q 的伪标签或熵统计。

## 一、模块定义

线性映射 W（64×64，或对角版），两侧共享，目标函数：

```
L = CE(W z_fit, y_fit) + λ·‖Cov(W z_fit) − Cov(z_adapt)‖²_F + μ·‖mean(W z_fit) − mean(z_adapt)‖²
```

- W 初始化为单位阵 ⇒ (λ=μ=0) **正好退化回 Cross**（可审计的零假设）
- 训好后分类器按冻结设置重训：`LogisticRegression(C=1, max_iter=3000)` 拟合 `W z_fit`，预测 `W z_eval`
- **超参只在源端留出港（leave-one-port-out，20 个 episode）上选**，选定后原样用于 5 个伪目标

## 四、判定与解释

1. **未达标**：本轮设定的门槛是「超过 Cross / Mean-only / CORAL-T2S 的较好者」；模块在每一对上都等于或低于
   Cross，并在 Mean-only 有效的两对上明显更差（−.063、−.010）。⇒ **不进入下一版**。
2. **源端增益不迁移，这是第三次独立复现**：
   - E03：无标签统计量能预测 Mean-only 的符号（AUC 0.92），但幅度可忽略；
   - E04：港级留出的规则坍缩为恒选 Cross，且二选一 oracle 仅 +0.002 BA；
   - E05：源端 LOO 上 +1.7 BA 的线性模块，在伪目标上增益 0。
   三次都指向同一件事：**在冻结表示上做特征空间（一阶/二阶/源监督线性）适配，收益不跨港迁移。**
3. 这不等于「适配无用」，而是**在当前冻结表示 + 当前源监督量 + 当前评价支撑下，特征空间线性适配不是抓手**。

    这是唯一还没被本轮覆盖的一层；成本是一次重训（服务器 4080S 可用），不是新数据。
  - **(B) 回到源监督与类别覆盖**：E02 的规范协议显示 Cross BA 仅 .28–.56，而独立监督参照 `in_ref` 在同类评价集上
    可达 BA .35–.74 / Acc .71–.99 ⇒ **表示可分性**与类别支撑仍是主要瓶颈，可能需要更多源监督或类别平衡，而非新的对齐项。
