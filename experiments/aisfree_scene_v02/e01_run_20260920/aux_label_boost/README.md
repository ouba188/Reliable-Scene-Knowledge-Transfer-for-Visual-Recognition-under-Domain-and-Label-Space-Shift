## 三、能说什么 / 不能说什么

**能说**：
1. 可评价量从 4–430 提升到 190–1,056，其中 **Jebel Ali 达到先前设定的「≥1,000 且最少类 ≥50」判定标准**。
2. 在 n≥355 的折上，**B0 与 B1 的差异 ≤3.6 个点**（Jebel Ali +3.6、Rotterdam −1.1、Shanghai −0.2、Port Klang +3.1），
   即「选哪个候选头」这点差异在统计上仍接近噪声边缘；Shanghai 上几乎为零。
3. **Full≡B1 在四档口径下全部成立**（rescue=harm=0）——知识筛选的零增量结论**在更大的分母上再次成立**，
   不是小样本错觉。

**不能说**：
- 不能说「知识模块无效」；只能说**在本批六折与当前判据（tau 残差）下，知识没有改变任何一次预测**。
- 不能把 B0/B1 的差异当结论：除 Jebel Ali 外 n 仍偏小，且 B0 的选择本身有随机性。
