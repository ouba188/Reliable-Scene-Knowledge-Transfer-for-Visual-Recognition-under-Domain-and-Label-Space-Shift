  **（观测矩, 预测矩）不匹配**，而不是机制间差异。

## 2. 关系单元分解（逐 (B,D)）

- 四折的共同结构：**只有 (b, D0) 与 (b, D3) 活跃**，且每个 (B) 组都如此（见 `p1_relation_cells.csv`）。
- D1（锚地）在目标端**普遍缺可用值**：Shanghai 的 (b,1) 全部 `too_few_available_objects (count 0)`
  —— 该港的锚地图层在本批数据中未观测；这是**层覆盖**问题，不是模型问题。
- D2（航道）在被规则停用（`disabled_by_source_support`）。
- 因此本批可检验的知识=「岸距 + SAR 群体密度」两类，且岸距在离岸域（>500 m）内区分度有限。
- `p1_relation_cells.csv` 另给出每格的 count/blocks/观测均值/预测范围/零值比例/最差残差。

## 3. 与主表结论的对应

- retained 全 8/8 ⇒ Full≡B1，在 P1 视角下原因清楚：**活跃单元上的（观测−预测）残差都小于 tau**，
  而不是「模型分不出候选」。
- 若要产生剪枝，需要 (a) 更细的层覆盖（D1/D2 在目标端可用）或 (b) 关系矩在这些单元上真正有
  条件区分力——两者都不是靠调 tau 能解决的，按冻结规则不在本轮改。
