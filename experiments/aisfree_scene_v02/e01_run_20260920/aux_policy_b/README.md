# (b) 决策粒度策略 v1（源端训练，目标端评估）（**含勘误：OBJ 与 STK 的关系**）

> **勘误（2026-09-21，评审裁定）**
> 1. **「OBJ（逐对象 oracle）高于任何可用策略」不成立**：Fujairah coarse 上 STK=.201 > OBJ=.153。
>    原因是**两者不在同一函数族**：OBJ 只在 255 个**等权子集**中取最优；而 STK 是
>    `softmax(W[p1;…;p8]+b)` 的**新分类器**，可跨类别重组证据，**OBJ 不是 STK 的上界**。
>    正文与表中涉及该比较的表述一律按此更正。
> 2. **STK 没有输入港口知识**，其增益不是「知识被利用」的证据；且其训练源池为 fit∪meta∪cal，
>    其中部分基础模型预测属于训练内预测（未做交叉拟合），因此**不能代表标准 stacking**。
> 3. Shanghai 的 +.035/+.013 记为**单次观察**，不称「稳定收益」；
>    **本轮不用 STK 判定「可迁移逐对象选择已被充分测试而失败」**。

## 二、三条读数

1. **B0 ≈ B1 ≈ FIX 全部在噪声内**（差 ≤.03）：选哪个头、选哪个固定子集、等权平均，对目标端结果几乎无区别。
   → 与上界诊断一致：**固定子集族没有可利用的空间**。
2. **源端训练的逐对象堆叠（STK）只在 Shanghai 上是稳定正收益**（+.035 acc / +.013 BA）；
   其余折为持平或正负相抵（Port Klang −.016/−.029、Fujairah +.090 acc 但 −.059 BA、Jebel Ali +.014/−.018）。
   → **一个朴素的源端条件策略并不能稳定超过现在的聚合方式。**
3. **OBJ（逐对象 oracle）在所有视图上都显著高于任何可用策略**（+.047 ~ +.154）。
   → 逐对象空间**确实存在**，但**源端训练的简单选择器拿不到它**。这正是「决策粒度」这一层的真实难度：
   不是「换个子集」的问题，而是需要**逐对象可迁移的选择信号**（源端可信、目标端可迁移）。

## 三、结论与后续

- **可以停止**：调 tau、换固定子集、换等权/单头聚合（三条都已被证明没有空间）。
- **(b) 的下一步**（若要继续）：构造**逐对象可迁移的选择信号**并做源港留一验证；本轮已证明「直接源端训练 LR 堆叠」不够。
- 与 (a) 的交叉结论：域间隙（(a)）比决策粒度缺口（(b)）大一个量级 → **优先级应给表示/适配层**。
