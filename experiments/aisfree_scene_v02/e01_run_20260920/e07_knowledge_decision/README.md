# E07 知识作为**决策信号**：单一干预结果（结论：该用法无效，且单调有害）

**背景**：按裁定选 (B) 路线的延伸——用修正后的协议直接检验知识模块。本轮把知识用作**决策信号**：
关系模型为每个类别预测的时刻剖面 `phi[j,x,c,d]` 与对象自身观测剖面 `m[x,d]`（图像派生、部署合法）
构成似然项，对冻结分类器重加权

```
score(c|x) = p(c|x) · exp( −λ · d(x,c) ),   d(x,c) = mean_j Σ_{d∈enabled} ((phi−m)/σ_d)²
```

- **λ=0 时严格等于 Cross**（可审计零假设）
- **打乱对照**：把 `c ↔ 时刻剖面` 的对应关系随机置换后做同样重加权（证明信号来自知识本身，而非多了一个项）
- **λ 只在源端留出港选择，且显式排除全部伪目标港（Qingdao/Shanghai）**——修正 E05 的选择路径缺陷

## 一、λ 选择（源端，已排除伪目标港）

| λ | 0.00 | 0.05 | 0.20 | 1.00 | 5.00 |
|---|---:|---:|---:|---:|---:|
| 源端平均 BA | **0.5516** | 0.5443 | 0.5234 | 0.4653 | 0.2964 |

**λ=0 胜出**：知识项取任何正权重都**单调降低** BA ⇒ 该用法下知识信号不仅无益，且随权重增大迅速有害。

## 三、这次实验说明了什么（严格限定范围）

**说明**：把「源端关系模型预测的类别时刻剖面」当作**逐类似然乘子**去重加权冻结分类器，
在本数据与协议下**无收益、且单调有害**。一个可信的机制解释是：该剖面携带的是**源端类别先验/源端条件分布**，
在跨港标签机制不同时，按它重加权会把预测推向源端分布，从而伤害目标端。

**没有说明**：
- 不等于「知识无用」。本轮只检验了**一种用法**（乘子式重加权）。
- 未检验的用法至少还有两类：
  1. **作为条件先验**（如按港口的静态地理知识给类别先验/路由），需要在协议上先确认哪些知识字段对伪目标港是
     部署合法的（港口知识中的 AIS 派生统计对伪目标港属于目标派生信息，**不得使用**；OSM/几何部分可用）；
  2. **作为特征**（把知识向量并入分类器输入，而非乘在概率上）。
- `m`（4 维时刻观测）本身是粗粒度信号，这也是该乘子的信息量上限之一。
