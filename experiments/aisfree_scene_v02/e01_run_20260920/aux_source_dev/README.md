# 源端开发台与 (a)/(b) 前置结果（2026-09-21）

**性质**：源端（source-only）诊断，用冻结头在源港实例上做前向，**不使用任何目标端真值**。
用途：为 (a) 覆盖/可分性诊断与 (b) 决策粒度策略提供开发集——两者共用同一台子。

## 一、台子怎么搭的

- 源端实例定义：`deployable_offshore==1` 且产品属于该折的源港产品集合（`source_fit_products ∪ source_meta_query_products ∪
  source_calibration_adapt_products ∪ source_calibration_products`），标签取对象表 `ais_final_class` 且落在该折细类词表内
- 逐头概率：**用冻结头现算**（`heads/h*.pt` + `feature_scaler.npz`，CPU 前向；复用 `e01_glue_rev1.head_probs`）
  ——不读取 `filter_inputs.npz`（那是目标适配池，源端标签在其中命中 0/612）
- 审计：同 `oracle_audit.py`（255 子集 / 单头 / 逐对象），`view=source`

## 三、三条读数（源端，大样本）

1. **固定子集 ≈ 最佳单头，在源端同样成立**（.744=.744、.800=.800、.636→.639、.775→.778、.640→.647）。
   → 目标端「整折统一保留子集族已饱和」**不是小样本错觉**，是本预测族的结构性质。**这是本轮最硬的一条。**
2. **B1（8 头等权）在五折全部弱于最佳单头**（−.026/−.050/−.023/−.017/−.020）。
   → 等权聚合是系统性负贡献，B1 不是强基线（此前只能用点估计说，现在有五折大样本证据）。
3. **单头并集上限显著高于固定子集**（+.029/+.082/+.070/+.030/+.072），而其值≈逐对象上限。
   → 剩余空间确实在**决策粒度**（逐对象/条件选择），而不是在选哪些头或 tau 阈值。

补充：源端「无头可答」占 B1 错误 47%–80%，**低于目标端的 87.5%** ⇒ 目标端错误里「头部族根本没有正确答案」的比例更高，
说明其中一部分来自**跨港域偏移**（对应 (a) 的覆盖/可分性方向），一部分来自决策粒度（(b)）。

## 四、(a)/(b) 怎么并行（结论）

- **共用**：本开发台（源端标签 3–6k/折 + 冻结逐头概率 + 255 子集）。
- **(a) 覆盖/可分性诊断（CPU，可立即做）**：源端逐类 recall 与 support、每类「是否有任何头可答」、
  目标端缺失类别的分布（对照 24 港层覆盖与词表）→ 结论只用于判断**是否需要重训 encoder/头**。
- **(b) 决策粒度（CPU，可立即做）**：在源端开发条件策略（逐对象/逐港/按 group 选择子集），
  **在目标端评估** → 这是唯一被证明还有空间的方向。
- **顺序约束**：若 (a) 结论是要重训 → 先重训，再在**最终预测**上定 (b)（否则 (b) 的产物作废）。
  若 (a) 显示只需换词表/加类别而无需换表示 → (b) 可与 (a) 并行到底。
